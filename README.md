# CrystalCharting
Tema progetto: Noleggio Barche

Componenti principali:
- Catalogo Filtrabile (mostra diversi tipi di imbarcazioni)
- Dettaglio Prodotto (il cliente sceglie l'imbarcazione e viene indirizzato al calendario)
- Inserimento dati con controlli (admin inserisce barche nel catalogo)
- Calendario (con inserimento dati prenotazione e piccolo recap imbarcazione prenotata e costo totale)
